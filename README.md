# rookie-card-widgets
All of the code, files and instructions to implement the Rookie Card Widgets.

For more information about the Rookie Card Widgets visit our website RookieCardPrices.com.

Use the Rookie Card Widget to display any card's basic data on your website blog or app. Simply download the file type of choice, then locate your card of choice in the first column. Copy the widget code snippet from the corresponding adjacent code cell. Place this code into any html block or editor that excepts this type of code.

These widgets are completely free to use. Please always retain the links within the widget code.
